Designed and operated a real-time streaming pipeline using Apache Kafka and Spark Structured Streaming. AutoLoader File-Notification Multiplexer Pipeline

Engineered a metadata-driven AutoLoader pipeline where files landing on ADLS Gen2 trigger Azure Event Grid notifications queued to Azure Queue Storage. AutoLoader (cloudFiles, file-notification mode) streams records into a centralised Multiplexer Delta table. Dedicated streaming jobs per dataset then apply SCD Type 1 or SCD Type 2 to downstream Silver tables in near-real-time.
