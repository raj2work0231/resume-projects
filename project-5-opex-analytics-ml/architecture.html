OPEX Analytics, Geospatial Dashboards & Contract Cost Analysis

Ingestion and analysis of infrastructure OPEX datasets on Azure Databricks, Uber H3 geospatial dashboards, and a metadata-driven PDF extraction framework that creates a structured invoicing dataset from supplier invoices — then joins it with the power supply asset register to compare theoretical contract costs against actual billed amounts and identify contracts for recalculation.

Solution Overview

This platform centralized fragmented operational expenditure data from multiple infrastructure asset categories (power supplies, poles, underground cables, right-of-way) into Azure Databricks. Business rules attributed costs to the correct cost centres. A metadata-driven PDF extraction framework — where each supplier and invoice type is registered as a configuration row — drove structured extraction from supplier invoices, creating a normalised invoicing dataset. This invoicing dataset was then joined with the infrastructure power supply asset register, which holds the theoretical (contractual) cost per asset and billing period. By comparing the theoretical cost against the actual invoiced amount, the platform identified billing variances and flagged contracts where recalculation or renegotiation was warranted. Interactive Power BI dashboards with Uber H3 geospatial mapping provided nationwide cost visibility.

Metadata-Driven PDF Extraction Framework

Each supplier and invoice type is registered as a row in the pdf_extraction_config Delta table (regex field patterns, filename routing pattern). The framework reads active configs, uses pdfplumber to extract raw text from each PDF, applies supplier-specific regex patterns to parse structured fields, normalises extracted values, and writes a unified invoicing dataset to a Silver Delta table.

Contract Cost Analysis — Theoretical vs Actual

The invoicing dataset (actual billed amounts) is joined against the infrastructure power supply asset register (theoretical contract cost per asset and billing period). Variance and variance percentage are computed per contract line. Records where actual cost exceeds theoretical by more than the configured threshold are flagged as RECALCULATE — providing evidence for supplier renegotiation.

Impact & Outcomes

  • Metadata-driven PDF framework enabled structured invoicing datasets from all supplier invoice types without per-supplier code changes
  • Contract cost analysis identified billing variances per asset and billing period, providing direct evidence for contract recalculation
  • OCR automation replaced manual invoice data entry across hundreds of supplier PDFs
  • Geospatial dashboards provided nationwide infrastructure cost visibility by H3 region
  • Enabled targeted supplier renegotiations backed by data-driven variance evidence
